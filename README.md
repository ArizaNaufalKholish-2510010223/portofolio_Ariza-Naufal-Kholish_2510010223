**Ariza Naufal Kholish — 2510010223**

Landing page katalog empat unit usaha: F&B, Percetakan & Dokumen, Konsinyasi, dan Jasa Kreatif. Dibuat dengan HTML, CSS, dan JavaScript murni, tanpa framework atau dependensi runtime.

- [Alamat website GitHub Pages](https://arizanaufalkholish-2510010223.github.io/portofolio_Ariza-Naufal-Kholish_2510010223/)
- [Repository](https://github.com/ArizaNaufalKholish-2510010223/portofolio_Ariza-Naufal-Kholish_2510010223)

## Menjalankan secara lokal

Unduh atau clone repository, lalu buka `index.html` di browser. Tidak memerlukan instalasi atau proses build. Live Server dapat dipakai saat pengembangan.

## Struktur utama

```text
index.html              Struktur dan konten semantik
style.css               Tampilan, responsif, dan animasi
script.js               Data unit, pencarian, dialog, menu, dan transisi
assets/                 Empat foto ilustrasi kategori
logo-web.png            Logo untuk tampilan website
logo-it-solution.png    Logo resolusi tinggi dengan latar transparan
.nojekyll               Penanda website statis untuk GitHub Pages
```

## Fitur

- Empat unit dengan deskripsi, foto ilustrasi, dan detail layanan.
- Pencarian lokal berdasarkan kebutuhan, misalnya `print tugas` atau `titip jual`.
- Menu buka/tutup, akordeon informasi, dan transisi pembuka mengikuti scroll.
- Tata letak responsif, kontrol keyboard, Escape untuk menutup dialog, dan dukungan pengurangan gerakan.

## GitHub Pages

Sumber publikasi: branch `main`, folder `/ (root)`, melalui **Settings → Pages → Deploy from a branch**. Semua aset memakai jalur relatif sehingga tetap bekerja pada alamat proyek GitHub Pages.

## Informasi operasional

Kontak, jam operasional, lokasi, dan harga masing-masing unit menunggu data terverifikasi dari pengurus. Perbarui objek `unitDetails` di awal `script.js` dan bagian informasi pada `index.html` ketika data tersedia. Foto kategori merupakan ilustrasi layanan.
